## Questões

1. **(2,0 ptos.)** Associe cada conceito (coluna A) à sua respectiva descrição (coluna B).

| Conceito                               | Descrição                                                                                                             |
|----------------------------------------|-----------------------------------------------------------------------------------------------------------------------|
| A. Conjunto enumerável                 | 1. Técnica que permite definir novas funções procurando o menor valor que satisfaz certa propriedade.                 |
| B. Diagonalização de Cantor            | 2. Modelo capaz de receber a codificação de outra máquina e de sua entrada, simulando sua execução.                   |
| C. Função recursiva primitiva          | 3. Argumento clássico usado para mostrar que certos conjuntos não podem ser listados completamente.                   |
| D. Minimização                         | 4. Problema clássico no qual se busca uma sequência de peças que iguale duas concatenações.                           |
| E. Máquina de Turing universal         | 5. Classe de funções totais obtidas por composição e recursão primitiva a partir de funções iniciais.                 |
| F. Linguagem decidível                 | 6. Conjunto cujos elementos podem ser colocados em correspondência com os números naturais.                           |
| G. Teorema de Rice                     | 7. Afirma que toda propriedade semântica não trivial de linguagens reconhecidas por máquinas de Turing é indecidível. |
| H. Problema de Correspondência de Post | 8. Linguagem para a qual existe uma máquina de Turing que sempre para e responde sim ou não corretamente.             |
